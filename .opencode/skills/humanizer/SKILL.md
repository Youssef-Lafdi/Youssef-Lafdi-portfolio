# Humanizer Skill

When the user asks you to "humanize" a text, apply the following rules to rewrite it:

1. **Remove AI Buzzwords:**
   - Delete or replace generic phrases like "ausgeprägtes Interesse", "nahtlos integrieren", "maßgeblich beitragen", "umfassende Kenntnisse", "leidenschaftlich".
   - Replace them with concrete, direct language.

2. **Vary Sentence Structure:**
   - AI tends to use the same sentence length. Mix short, punchy sentences with longer ones.
   - Avoid starting multiple consecutive sentences with the same word (e.g., "Ich habe... Ich habe...").

3. **Active Voice & Directness:**
   - Use active voice instead of passive (e.g., "Ich baute den Bot" instead of "Der Bot wurde von mir gebaut").
   - Be direct. Germans value clarity (Klarheit).

4. **B2/C1 German Naturalness:**
   - Use natural German connectors (deshalb, dadurch, dabei, trotzdem) but don't overuse them.
   - Ensure the tone is professional but sounds like a real person wrote it, not a machine. 

5. **Keep the facts intact:**
   - Do NOT invent new achievements. Only change the *style*, not the *substance*.

**Example Transformation:**
- *AI (Bad):* "Ich habe ein ausgeprägtes Interesse an IT und Automatisierung und eigenständig ein Automatisierungsprojekt umgesetzt."
- *Human (Good):* "Ich interessiere mich für IT und Automatisierung. Deshalb habe ich einen eigenen Telegram-Bot mit Python entwickelt."
