# AGENTS.md

Personal portfolio for Youssef Lafdi — Astro 5 static site (canonical URL `https://youssef-lafdi.de`).

## Commands
- `pnpm dev` — dev server (alias: `pnpm start`).
- `pnpm build` — production build to `dist/`.
- `pnpm preview` — serve the built `dist/`.
- There are **no** test, lint, or typecheck scripts. `astro check` / `@astrojs/check` is not installed; do not assume it works.

## Tooling
- Package manager is **pnpm** (`pnpm-lock.yaml` + `pnpm-workspace.yaml`). Do not use npm/yarn.
- TypeScript is strict via `astro/tsconfigs/strict`.

## Non-obvious conventions
- **Tailwind v4** is wired through the Vite plugin `@tailwindcss/vite` in `astro.config.mjs`. There is **no `@astrojs/tailwind` integration and no `tailwind.config.js`** — do not create one. Configure the theme with `@theme` inside `src/styles/global.css`, which is just `@import "tailwindcss";`.
- i18n is configured in `astro.config.mjs`: default locale `de` with `prefixDefaultLocale: false`, so German pages live at the root (`/`) and English under `/en/` (new English routes go in `src/pages/en/...`; that directory does not exist yet — only `src/pages/index.astro` is present).
- `.astro/` is generated by Astro (types + content cache) — do not edit it.
- `pnpm-workspace.yaml` declares native build approvals (`allowBuilds`) for `esbuild`, `sharp`, `msgpackr-extract`, `onnxruntime-node`, `protobufjs`. Keep all of these if regenerating the file, or pnpm installs will fail/blocked builds.
